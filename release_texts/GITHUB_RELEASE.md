# Apocalypse – German Uncut / TRUE NTSC 60 Hz v1.0 RC1

**by Bratwurstmensch**

A restoration patch for the German PlayStation release of *Apocalypse*. The PAL edition restores red blood, dismemberment and missing gore/blood-fountain effects while preserving the full German localization. The optional TRUE NTSC edition uses the genuine US SLUS-00373 gameplay/rendering/timing code and applies the German localization on top, providing authentic NTSC 60 Hz behavior and viewport rather than a PAL-to-NTSC hybrid.

Two original disc images are required for the TRUE NTSC builder (German SLES-00835 + USA SLUS-00373). No complete game image is included.

RC1 has been verified through boot, intro, main menu and initial gameplay, including German speech/text, red blood, dismemberment and restored blood fountains. A full playthrough is still recommended before the Final tag.
